Sevanna's action button — gold "foil" primary, emerald outline secondary, quiet ghost; use for any call to action ("Inscribirme", "Ver curso").

```jsx
<Button variant="primary" size="lg">Inscribirme</Button>
<Button variant="secondary">Ver temario</Button>
<Button variant="ghost" size="sm">Cancelar</Button>
```

Variants: `primary` (gold foil), `secondary` (gold outline), `solid` (emerald fill), `ghost`. Sizes `sm | md | lg`. Supports `iconLeft`/`iconRight`, `fullWidth`, `disabled`. Labels are set UPPERCASE with wide tracking automatically.
