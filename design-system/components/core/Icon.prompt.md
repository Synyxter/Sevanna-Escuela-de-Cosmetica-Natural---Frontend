Thin-line icon (Lucide) tuned to Sevanna's delicate stroke. Requires the Lucide script on the host page. Default stroke-width 1.5 keeps the elegant line quality.

```jsx
<Icon name="leaf" size={22} />
<Icon name="flame" size={18} color="var(--accent)" />
```

Use sparingly beside labels; prefer botanical/craft glyphs (leaf, flame, droplet, sparkles, flower).
